# Német gyakorló

Interaktív német tanulóoldal a heti tanfolyami PDF-ek alapján.

## Funkciók

- szókártyák német→magyar és magyar→német irányban
- témakör szerinti szűrés
- német kiejtés böngészőből (`de-DE`)
- opcionális automatikus felolvasás
- ismert / még nem ismert szavak követése
- interaktív kvíz
- kereshető szótár
- a haladás mentése a böngésző `localStorage` tárhelyén

## Frissítés

Az új heti tananyagok szókincse és kvízei a `data.js` fájlban bővíthetők.
